What happens when you press Ask

  1. Cache — exact match, then near-duplicate wording
  2. Rewrite — the question becomes several search queries
  3. Vector search — passages with the same meaning
  4. Keyword search — passages with the same words (BM25)
  5. Fuse — combine both lists by rank position
  6. Rerank — score each candidate for absolute relevance
  7. Threshold — drop weak passages; if none survive, refuse
  8. Generate — answer using only those passages
  9. Verify — check citations are real and every sentence is supported
