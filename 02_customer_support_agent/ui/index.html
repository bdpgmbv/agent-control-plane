What happens to each message

  1. Redact — personal data removed before anything is logged
  2. Classify — the intent decides which tools exist this turn
  3. Escalate? — asked for a human, abuse, or going in circles
  4. Tool loop — model asks for a tool, tool runs, result goes back
  5. Each tool call — permission, validation, idempotency, retries, audit
  6. Escalate? — needs approval, or the agent got nowhere
